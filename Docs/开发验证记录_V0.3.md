# 心塔开发验证记录 V0.3

> 验证日期：2026-08-13  
> 版本：0.3.0（Build 10）  
> 定位：本地经营总览

## 本版新增

- Mac 左侧导航增加“经营总览”；
- iPhone“更多”增加“经营总览”入口；
- 可选择本月、上月、本年或全部历史周期；
- 汇总有效预约、完成、取消、爽约和待确认付款数量；
- 分别汇总已付款预约标价、余额抵扣标价和已退款标记金额；
- 按服务项目汇总预约数、完成数和已付款预约标价；
- 自动排除改期产生的历史预约行，避免同一订单重复计算；
- 对部分付款和写在备注中的改期费给出数据缺口提示。

## 统计口径

1. 周期归属以预约开始时间为准，周期结束时间采用开区间，跨月边界不会重复统计；
2. “待规则同意”不算有效订单，“已改期”历史行不重复计入；
3. “已付款预约标价”来自预约建立时保存的服务标价，不读取微信或银行流水；
4. 已付款但已取消的订单按当前“不可退单”规则保留在已付款标价中；
5. 标记为“已退款”的订单不计入已付款标价，并单独显示退款标记金额；
6. 余额抵扣单独显示，不冒充现金收入；
7. 部分付款尚无实收金额字段，暂只计笔数、不计金额；
8. 200 元改期费目前仅存在备注中，暂不计入金额汇总。
