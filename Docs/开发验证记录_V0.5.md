# 心塔开发验证记录 V0.5

> 验证日期：2026-08-13  
> 版本：0.5.0（Build 12）  
> 定位：套餐权益与项目订单

## 本版新增

- 新增“套餐与项目”订单模块，Mac 左侧导航和 iPhone“更多”均可进入；
- 支持周期套餐、起名改名和空间服务订单；
- 订单保存客户、服务、目录价格、约定总价、数量/面积、付款状态、订单状态和规则快照；
- 支持订单全款、部分付款、余额抵扣、后续补款和退款；
- 套餐保存总次数、已核销次数、剩余次数和有效期；
- 新建预约可选择已激活、未过期且仍有次数的对应套餐，保存后自动核销一次；
- 套餐最后一次核销后自动完成，过期套餐不能继续核销；
- 套餐预约标记为“套餐权益”，不会重复生成咨询费流水；
- 青少年改名等服务强制填写监护人和服务对象，只建立项目订单，不建立未成年人咨询；
- 起价服务不得低于目录起价；按平方米服务根据面积计算最低价，仍可记录双方最终约定总价；
- 经营总览纳入项目/套餐订单流水，并在最近流水中区分预约和订单来源；
- 加密备份与恢复包含订单、订单流水和权益核销，同时兼容旧 V2 备份。

## 开发默认规则

1. 套餐未付清时保持“待付款”，全额现金或余额覆盖后才激活；项目订单默认 50% 首款、50% 尾款，首款后可进入执行；
2. 套餐从订单建立日开始计算有效期；
3. 创建套餐预约即核销一次，预约取消是否返还次数当前默认不自动返还，避免绕过“不可退单”规则；
4. 项目订单完成由咨询师人工确认；
5. 项目变更服务对象、范围、面积或交付内容时，应另行确认费用和时间；
6. 项目订单默认告知文本已经加入设置页，正式运营前仍需本人确认版本。
