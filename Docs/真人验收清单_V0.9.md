# 心塔 V0.9 真人验收清单

> 版本：V0.9.0（Build 16）
>
> 适用对象：内部小范围试用
>
> 原则：先用虚构资料完成全部门禁，再决定是否录入正式客户资料

## 1. 验收前准备

- [ ] 先导出一份加密备份，并执行“仅校验备份”。
- [ ] Mac 与 iPhone 均确认显示 V0.9.0（16）。
- [ ] 全程使用虚构客户、虚构选题、虚构订单和虚构流水。
- [ ] 不上传真实姓名、微信、手机号、录音、转写、照片或健康信息到外部服务。
- [ ] 明确当前朋友圈和小红书指标仍以人工录入或 CSV 为主，系统不会自动登录或操作平台。

## 2. 安装与基础回归

- [ ] Mac 解压试用包后可正常启动，旧数据仍可打开。
- [ ] iPhone 覆盖安装后可正常启动，既有本地数据未被清空。
- [ ] 应用密码、Face ID/Touch ID、自动上锁正常。
- [ ] 10 秒提醒测试能收到系统通知。
- [ ] Mac 与 iPhone 各完成一次 10 秒录音、回放、本机转写自检。
- [ ] Mac 连续口述 2～3 分钟并停顿、改口，已显示文字不会整段消失。
- [ ] 导出加密备份后可通过完整性校验；恢复演练只使用虚构数据。

## 3. 原有经营闭环

- [ ] 建立虚构客户、产品、客户订单和预约，确认新订单默认不收款。
- [ ] 记录部分付款与尾款，付款状态和现金净实收正确。
- [ ] 套餐预约先占用、咨询完成后核销；取消时可人工选择返还或不返还。
- [ ] 咨询资料、同意、转写、摘要草稿、人工批准、录音交付和归档门禁正常。
- [ ] 经营总览中现金收入、退款、余额抵扣和净实收与测试流水一致。

## 4. 品牌增长 M1：内容闭环

- [ ] Mac 左侧和 iPhone“更多”都能进入“品牌增长”。
- [ ] 品牌设置显示固定的品牌定位、目标人群、语气、禁用表达和版本。
- [ ] 用“个人观点”“公开资料”或“品牌素材”建立一个虚构选题。
- [ ] 同一选题产生朋友圈、小红书两个独立草稿；两份文案不是简单复制。
- [ ] 两个平台必须分别人工批准，不能一次批准全部版本。
- [ ] 修改已批准草稿后，批准立即失效，重新批准前不能排期。
- [ ] 只允许已批准版本进入发布日历；登记发布时保留平台、时间、编号或链接以及文本快照。
- [ ] 停止本地 AI 后仍能手工建立、编辑、批准、发布和复盘内容。

## 5. 品牌增长 M2：数据、归因与复盘

- [ ] 为一条测试发布记录人工新增指标快照，未提供字段显示“未提供”而不是 0。
- [ ] 再新增一次指标快照，旧快照仍保留且不会被覆盖。
- [ ] 导入一份虚构 CSV；无效行不会写入部分数据，并能看到可理解的错误提示。
- [ ] 只有勾选“已对照平台后台核对”的快照进入复盘和实验对比。
- [ ] 把测试内容关联到测试客户，再建立测试预约、订单和付款。
- [ ] 品牌首页和每周复盘显示的询盘、预约、成交、现金净实收与经营数据一致。
- [ ] 只知道平台、不知道具体内容时，显示“只确认平台”或“无法归因”，系统不猜测内容。
- [ ] 每周复盘区分已确认事实、人工结论、数据缺口和下周实验；人工确认前不作为正式结论。

## 6. 品牌增长 M3：素材授权与撤回

- [ ] 未建立独立“匿名化内容使用”同意时，客户素材不能进入内容工作台。
- [ ] 客户素材必须保存允许范围、形式、平台、期限、撤回方式和确认时间。
- [ ] 去除姓名、昵称、联系方式、精确日期、地点、单位和可组合身份线索。
- [ ] 原始录音片段不能作为客户品牌素材导入。
- [ ] 两次去身份化复核完成后，且平台和期限匹配时，素材才显示可用。
- [ ] 撤回授权后，素材和未发布草稿立即停止复用。
- [ ] 已发布的测试内容只建立“人工下架或修改”任务，应用不擅自操作外部平台。
- [ ] 授权、撤回、处理任务和素材状态能随加密备份恢复；凭据和令牌不进入备份。

## 7. 品牌增长 M4：平台能力与实验

- [ ] 平台自动化页明确显示每个平台的账号类型、官方能力、核验时间和数据方式。
- [ ] 未完成真实账号与权限核验的平台不得显示“已连接”或“自动同步成功”。
- [ ] 同步失败、令牌过期或缺少数据时，人工录入和 CSV 流程仍可继续使用。
- [ ] 失败同步不会覆盖最后一次成功快照，旧数据不会被显示成最新数据。
- [ ] 标题、发布时间、栏目或行动提示实验一次只改变一个主要变量。
- [ ] 实验只使用同口径、人工确认的数据；最终结论由本人填写并确认。

## 8. 目标设备与外部平台

- [ ] 在目标 M5 MacBook Air 上，边视频通话边运行本地 AI，记录摘要耗时、内存压力、机身温度和风扇/降频体感。
- [ ] 在实际咨询 iPhone 上完成覆盖安装、冷启动、权限、自检和提醒测试。
- [ ] 用真实账号核对朋友圈和小红书后台实际可提供字段，但不发布真实内容。
- [ ] 只有在账号类型、官方权限、令牌保存和失败恢复全部通过后，才允许启用对应自动同步。
