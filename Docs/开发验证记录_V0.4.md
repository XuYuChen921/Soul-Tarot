# 心塔开发验证记录 V0.4

> 验证日期：2026-08-13  
> 版本：0.4.0（Build 11）  
> 定位：真实收付款流水

## 本版新增

- 新增独立收付款流水，记录预约、客户编号、服务、类型、方式、金额、发生时间和备注；
- 支持咨询费全款/部分付款、退款、加急费、改期费、其他收款和余额抵扣；
- 新建预约时按实际付款选择自动建立首条流水，部分付款必须输入实收金额；
- 预约详情显示已覆盖咨询费、待收咨询费、现金净实收、额外费用和全部历史流水；
- 晚改期只有勾选“已实际收取”才生成 200 元改期费流水；
- 经营总览改用真实流水，金额按收付款发生时间归期，预约数量按咨询开始时间归期；
- 经营总览支持导出 CSV，使用客户编号而非客户姓名，并防止表格公式注入；
- 加密备份与恢复包含收付款流水；旧版 V2 备份仍可恢复；
- 旧版已付款、余额抵扣和已退款预约升级时自动建立待核对的迁移流水，重复升级不会重复建立。

## 统计口径

1. 现金收入包括咨询费、加急费、改期费和其他收款；
2. 现金净实收＝现金收入－退款；
3. 余额抵扣单独统计，不计为现金；
4. “已改期”历史行和“待规则同意”记录不计入经营订单；
5. 预约数量按咨询开始时间归期，金额按流水实际发生时间归期；
6. 应用不连接微信或银行卡，所有流水由咨询师人工确认后录入；
7. 旧版迁移流水保留“旧版迁移”标记，需与真实收款记录核对。
